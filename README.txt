DAREM AMIN - BIRTHDAY INVITATION WEBSITE

Files:
- index.html: first/cover page with the animated cover GIF and Open Invitation button.
- invitation.html: second page with the animated invitation and clickable hotspots.
- style.css: responsive layout and sweet-note popup styles.
- page1-cover.gif: first-page animation.
- page2-invitation.gif: second-page animation.

Buttons:
- Open Invitation opens invitation.html.
- Location opens a Google Maps search for The Riverside Lounge, Ismailia, Egypt.
- RSVP opens WhatsApp with a prefilled RSVP message; choose a recipient to send it.
- Photos opens a Google search for Darem Amin birthday party photos.
- Video opens YouTube search results for Darem Amin birthday party videos.
- Leave a Sweet Note first displays: “May all your sweet dreams be real soon .. Love you Daroumi ♥️”. After the visitor taps “Leave your message”, a text box appears. Submitting opens WhatsApp with the visitor's note prefilled, so they can choose a recipient and send it.

Hosting:
Upload all files together in the same directory; no folders are required. Set index.html as the site's entry page. The venue/date details and links can be edited in invitation.html if needed.
